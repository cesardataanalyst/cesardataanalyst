### 🚀 RappiPlus — Strategic Data Analysis
- Proyecto de análisis de datos orientado a evaluar el desempeño de un negocio digital y transformar información de diferentes fuentes en insights para la toma de decisiones.
El proyecto integra datos de ventas, costos, marketing, comportamiento de usuarios, retención y experimentación A/B, siguiendo un flujo analítico completo desde la validación de la calidad de los datos hasta la comunicación de resultados mediante un dashboard en Power BI.
- **Enfoque**: Se realizó una revisión inicial de los datasets para identificar: •	Valores nulos | Tipos de datos incorrectos | Valores numéricos inválidos | Duplicados | Consistencia de variables categóricas | Revenue total | Costos |  Gastos en Marketing | Profit.
- **Tools:** Python | SQL | Data Visualización | BI |
